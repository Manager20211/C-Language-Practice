## 💡 踩坑与反思总结（核心记忆点）
1. **内存安全**：`malloc` 必须判空；删除节点后必须防止悬空指针；重载数据前必须先 `free` 旧链表。
2. **字符串比较**：绝不能用 `==` 比较内容，必须用 `strcmp`。
3. **输入防御**：`scanf` 遇到不合规输入会卡死，复杂输入考虑使用 `fgets` 读整行再解析。
4. **链表断链**：删除尾节点时必须同步更新 `tail` 指针，否则下次挂载直接段错误。

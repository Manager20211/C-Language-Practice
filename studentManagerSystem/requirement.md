📄 项目需求书：学生成绩管理系统
项目名称：Student Management System
文件夹命名建议：studentManager
文件命名建议：main.c（如果你喜欢，也可以拆分成 .h 和 .c，甚至直接用链表）

一、 数据结构定义
你需要定义一个结构体来存储学生信息：

c
struct Student {
    char id[20];      // 学号（因为学号可能以0开头，用字符串）
    char name[20];    // 姓名
    float score;      // 成绩
};
存储方式：
你可以选择用 动态数组（配合 malloc），也可以选择用 链表 来存储多个学生。（推荐用链表，因为你刚学完，正好练手）。

二、 核心功能模块（CRUD）
程序启动后，要有一个死循环的菜单，提供以下选项：

添加学生 (Add)

提示用户输入学号、姓名、成绩。

将学生信息存入系统中（如果是链表，用尾插法；如果是数组，存入下一个空位）。

查看全部学生 (List)

遍历系统中所有的学生，按照格式打印出来。

格式要求：

text
学号           姓名           成绩
001            张三           95.5
002            李四           88.0
查找学生 (Search)

提示用户输入要查找的学号。

在系统中寻找匹配的学号，如果找到了，打印该学生的详细信息；找不到则提示“查无此人”。

删除学生 (Delete)

提示用户输入要删除的学号。

在系统中找到该学生并将其移除（如果用链表，注意断链和 free 防止内存泄漏；如果用数组，要把后面的元素往前挪）。

保存到文件 (Save)

将系统中当前所有的学生数据，写入到一个名为 students.txt 的文本文件中。

（提示：用 fopen 的 "w" 模式，配合 fprintf）。

从文件加载 (Load)

从 students.txt 中读取数据，恢复到系统中。

（提示：用 fopen 的 "r" 模式，配合 fscanf 循环读取，直到文件末尾）。

退出系统 (Exit)

释放所有申请的内存（防止内存泄漏），结束程序。

三、 工程要求
模块化：不要把所有的代码都塞进 main 里。每个功能（添加、查找、删除、保存）都要写成一个独立的函数。

安全性：malloc 要判断 NULL，用完后要 free。打开文件要判断 NULL。

交互友好：清屏（可选），每次操作完给出明确的成功或失败提示。

💡 开发建议（别急着写代码，先看这里）
一次性写几百行代码很容易崩溃，建议你按这个顺序写：

先搭菜单：把 while(1) 和 switch-case 搭好，每个 case 先打印一句话占位，保证能跑。

写“添加”和“查看”：先实现基础的数据录入和打印。

写“查找”和“删除”：这部分需要遍历，如果你用链表，小心指针断链。

最后搞文件：把保存和加载加上。
